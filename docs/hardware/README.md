# Hardware Documentation

Use these sections for the physical buoy:

- [Components](components/README.md) — inventory, photographs, identification status, datasheets, and firmware interfaces.
- [Wiring](wiring/README.md) — the current, firmware-backed connection maps.
- [Procurement](procurement/README.md) — purchasing list and sourcing notes.

Older hardware plans are stored in [the hardware archive](../archive/hardware/). They are retained for design history only and must not be used to wire the active build.

## Authority Order

1. Active firmware for signal and GPIO assignments.
2. Exact manufacturer documentation for voltage, pin order, and electrical limits.
3. Current wiring pages for the intended physical connection.
4. Archive documents for history only.

Photographs of representative modules help identify parts, but they do not prove that a physically installed board has the same regulator, level shifting, or connector order.
