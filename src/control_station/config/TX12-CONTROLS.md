# TX12 control plan

`tx12-channel-map.json` is the control station's editable display map. The production buoy firmware now decodes the first five ELRS channels over MAVLink; editing this file does not change EdgeTX mixes or buoy firmware.

The starter profile assumes a Mode 2 TX12 model with AETR output order. Confirm the output channels and directions in the active EdgeTX channel monitor before using them to command propulsion. The station visualizes fresh receiver-relayed values; it does not send these commands.

| Physical control | Channel | Intended buoy function |
| --- | ---: | --- |
| Right stick horizontal | 1 | Lateral movement, left/right component of the movement vector |
| Right stick vertical | 2 | Longitudinal movement, forward/reverse component of the movement vector |
| Left stick vertical | 3 | Motor power limit, bottom 0% to top 100%; scales every movement command |
| Left stick horizontal | 4 | Buoy yaw |
| SE, three positions | 5 | Low/middle disarm; high requests ELRS arm after low was seen |
| SF, three positions | 6 | Low/middle: buoy Wi-Fi telemetry; high: MAVLink telemetry through TX Backpack |
| SB, three positions | 7 | Low: direct Manual; middle: Manual Assist with heading hold; high: request the loaded mission |
| SC, three positions | 8 | Low stops and saves; middle records science without audio; high records science with audio (manual mode only) |
| SA, momentary | 9 | Hold while arming to capture manual Home; hold together with SD for one second to request Return Home |
| SD, momentary | 10 | Hold together with SA for one second to request Return Home |
| S1 and S2 | Unassigned | Pending |

When the optional EdgeTX `mixcal.lua` Lua Mixes script is installed, CH11–CH16 carry calibration enable, command, mode, test index, test power, and pulse duration. CH16 selects 10- or 20-second pulses. These outputs are reserved for the calibration workflow and do not replace any CH1–CH10 control. They require ELRS MAVLink RC forwarding with 16 channels enabled; see `src/tx12/README.md` for setup and abort behavior.

The two right-stick axes combine into a movement vector, so diagonal stick positions request movement at an angle. The TX12 lateral mix uses rear reverse, front-left forward, and front-right reverse for rightward input; leftward input reverses those motor directions. This mirrors the previous mix after the water trial showed that it translated in the opposite direction. The mixer initially compensates for the observed roughly half-strength reverse thrust by doubling reverse commands, then scales all three outputs together if any motor reaches its limit. Check the resulting direction and heading response in a short, low-power water trial. With the right stick centered, left-stick LEFT yaw runs only the front-right motor forward; left-stick RIGHT yaw runs only the front-left motor forward. The left-stick vertical power limit applies to movement commands, including yaw. To arm, first put SE low, then raise it with neutral movement sticks and the power stick fully down. To set a manual Home while arming, hold SA high during that SE low-to-high arm sequence; the firmware requires a fresh GPS fix with at least 5 satellites and HDOP at most 3.0. The buoy saves the captured Home in ESP32 nonvolatile storage, so it survives power cycles. After arming, release both SA and SD. To request manual Return Home, hold SA and SD together for one second; either button alone does nothing. Return Home requires fresh GPS and calibrated heading; it has no mission boundary and stops if GPS, heading, or radio control is lost. SE away from high is the stop/disarm control. A stale RC frame (500 ms) or fresh zero-link-quality report stops ELRS-driven motors and saves active microSD recording. Verify physical stick directions and channel values in the EdgeTX channel monitor with propellers removed before allowing propulsion.

SF only selects the telemetry route. Low and middle use buoy Wi-Fi for detailed sensors and power history. High uses low-rate MAVLink through the TX Backpack for battery/current, GPS, motor state, link status and channels. Buoy Wi-Fi can disconnect in either position without disarming TX12; the receiver's RC failsafe remains active. The TX12 model must actually output SF on CH6 for the switch to work. Verify CH6 in the EdgeTX channel monitor.

**SE on CH5 needs a radio-mode check.** [ExpressLRS MAVLink mode](https://www.expresslrs.org/software/mavlink/) allows Hybrid or 16ch/2 switch mode. In [Hybrid mode](https://www.expresslrs.org/software/switch-config/), CH5 is two-position, so the middle position of a three-position SE switch cannot be distinguished. The buoy treats values below 1300 microseconds as disarmed/ready and values above 1700 microseconds as an arm request. Intermediate values remain disarmed. Verify the configured ELRS arming method and actual CH5 output before using SE for propulsion.

The station's stick bars use 988-2012 microseconds as an approximate visual range and show the raw received value. Three-position indicators use the firmware's 1300/1700 microsecond thresholds; momentary buttons use the midpoint. These describe channel values, not guaranteed physical up/down positions. Verify physical direction against the TX12 output monitor.

SB/CH7 selects the control mode: low is direct Manual, middle is Manual Assist with compass heading hold, and high requests the loaded mission. Assist corrects yaw only while the buoy is moving and the yaw stick is centered. Yaw stick input turns the buoy; centering it captures and holds the new heading. Assist needs a loaded magnetometer calibration; if heading is unavailable, it leaves yaw correction off and reports the unavailable state. Mission start requires a valid uploaded route, mission Home and boundary, buoy at Home, fresh GPS, calibrated heading, SD readiness, and the arm interlocks. Mission controls and automatic collection are described in Mission Control. Returning SB to low or middle stops an active mission; cycle SE low then high to re-arm. Verify CH7 positions in the EdgeTX channel monitor before operation.

SC/CH8 controls manual SD and audio collection without a buoy Wi-Fi connection. Low is the idle/save position: moving SC there stops and saves an open session. Middle starts or continues science and telemetry collection without audio. High starts or continues the session with audio. Moving High to Middle stops audio while leaving the science session open; moving either recording position to Low closes and saves it. The switch only acts when entering a position. On boot or after radio link recovery, its current position initializes the control; move it away and back to issue an action. SC is ignored while SB requests mission mode, where mission control owns collection.
